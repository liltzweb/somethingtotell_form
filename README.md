# somethingtotell order form

Form pemesanan publik untuk website **somethingtotell** milik katalog liltz. Website sumber tetap private; repo ini hanya berisi form statis dan tidak memuat foto, audio, atau data pelanggan.

**Live form:** https://arjunafransesco.github.io/somethingtotell_form/

## Alur

1. Isi form.
2. Tekan **salin & buka Telegram**.
3. Ringkasan order disalin ke clipboard dan chat [@reeumen](https://t.me/reeumen) dibuka.
4. Paste ringkasan, kirim, lalu lampirkan media secara berurutan.

- Recolor: **+Rp2.000**
- Rush <24 jam: **+Rp4.000**

## Media

2 foto polaroid + 1 file musik MP3.

## Jalankan lokal

Gunakan HTTP server lokal agar Clipboard API dapat diuji dengan benar, atau akses deployment GitHub Pages pada homepage repo.
